첨부한 회의록 파일 혹은 첨부한 파일이 없으면 회의록에 미확인 폴더의 회의록 파일들을 보고서 양식에 맞게 보고서를 작성해서 결과 폴더에 저장해
보고서 양식은 별도 지정이 없으면 양식 보고서_양식 워드파일을 참고해 
보고서로 작성한 회의록 파일은 회의록 확인완료 폴더로 이동시켜줘
보고서 파일은 회의록 파일과 같은 이름으로 만들고 날짜는 제외해
